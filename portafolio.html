Sobre mi ruta de aprendizaje

Este portafolio recopila los temas, ejercicios y proyectos que he desarrollado a lo largo del curso de Fundamentos Web. Mi enfoque ha sido dominar el HTML Semántico y explorar cómo el CSS permite crear diseños modernos, estructurados y responsivos.

Proyectos y Actividades

1. Estructuración con HTML Semántico

Creación de páginas organizadas utilizando etiquetas como <header>, <nav>, <main>, <section> y <footer>. Esto mejora la accesibilidad y el SEO.

2. Formularios Web Interactivos

Implementación de formularios para captura de datos, incluyendo validaciones con atributos como required, minlength, y tipos de input específicos (texto, email, fecha, contraseñas).

3. Integración Multimedia

Uso de etiquetas <audio>, <video> y <iframe> para enriquecer la experiencia de usuario incorporando contenido visual y auditivo tanto local como externo.
